# 🛒 KopMatNu

A simple grocery list app for Android, built with Kotlin and Jetpack Compose.

## Features
- Add items to a grocery list.
- Remove individual items.
- Clear the entire list.
- See how many items are on the list.
- Automatically save the list when the app is closed.

## Built with
- Kotlin
- Jetpack Compose
- Android Studio

## Version
**1.0** – My first grocery list app.

## About
This app was created as a learning project while studying Android development.
